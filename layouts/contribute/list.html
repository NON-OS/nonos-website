Program Integrity

🔒

Anti-Abuse Policy

This program is designed to reward genuine contributors who add real value to NONOS. We actively monitor for and reject:

  • Spam contributions - Low-effort issues, trivial PRs, or generated content
  • Multi-accounting - Multiple accounts controlled by the same person
  • Duplicate submissions - Issues already reported or known issues
  • Gaming behavior - Any attempt to manipulate the reward system
  • Bot activity - Automated or scripted contributions

Accounts found violating these policies are permanently disqualified from all rewards.

✓ All contributions reviewed manually by core team
✓ Reward amounts determined by actual contribution value
✓ Transparent criteria publicly documented
✓ Program updates communicated in advance

Frequently Asked Questions

How do I qualify for rewards?

Star the repository, submit a valid issue, or open a pull request. Then connect your wallet and link your GitHub account to verify your contributions. Star rewards are instant; issues and PRs are reviewed before approval.

Are all issues rewarded?

No. Only valid, original, and useful issues qualify for rewards. Duplicate issues, low-quality reports, or issues that cannot be reproduced do not qualify. The reward amount depends on severity and impact.

How are PR rewards calculated?

Pull request rewards are based on code complexity, impact on the project, quality of implementation, test coverage, and documentation. Larger architectural contributions receive higher rewards than minor fixes.

When are rewards distributed?

Star rewards can be claimed immediately after verification. Issue and PR rewards are processed after review, typically within 1-2 weeks of approval. You can claim all available rewards at once.

Can rewards be denied?

Yes. The team reserves the right to deny rewards for any contribution that does not meet quality standards, violates the anti-abuse policy, or does not provide genuine value to the project.

What counts as abuse or spam?

Abuse includes multi-accounting, bot activity, trivial changes submitted solely for rewards, duplicate issues, false vulnerability reports, and any attempt to game or manipulate the reward system.

Can the program change?

Yes. Reward amounts, criteria, and program terms may be updated at any time. Changes will be communicated publicly. Contributions made before changes are evaluated under the terms in effect at submission time.

What wallet do I need?

You need an Ethereum-compatible wallet (MetaMask, WalletConnect, etc.) to receive NOX rewards. Make sure you control the private keys and can add custom tokens to view your NOX balance.
