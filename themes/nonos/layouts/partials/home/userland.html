Runs real software.

NØNOS implements a platform layer for the Rust standard library. Unmodified Rust applications compile for the x86_64-nonos target and install as signed capsules: threads, sockets, filesystem and all.

  • Compositor, terminal, and an editor with a full IDE shell
  • A browser engine rendering real pages over TLS
  • WiFi, DHCP, DNS: a complete network stack in capsules
  • Boots on real x86_64 laptops, not only in QEMU
