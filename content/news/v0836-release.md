## NØNOS v0.8.3.6-alpha

This release brings a refined user interface with new components, smoother animations, and an improved desktop experience.

---

### New UI Components

A comprehensive set of new interface elements:

- Badges
- Cards
- Dropdowns
- Glass panels
- Progress bars
- Sliders
- Tabs
- Toggles
- Tooltips

These components follow a consistent design language and enable richer application interfaces.

---

### Animation System

New animation capabilities with easing functions, timing utilities, and transition effects for smooth UI interactions. The framebuffer now includes blend operations for proper alpha compositing.

---

### Desktop Improvements

- Refined desktop icons with better state management
- New status bar with battery, network, and time display
- Improved settings panels for privacy, power, and system options
- Better time and date formatting

---

### Browser Updates

The browser has been reorganized with improved rendering, URL bar handling, and input processing. State management is now cleaner across browser sessions.

---

### Wallet Enhancements

The wallet backend has been improved with better RPC handling, stealth address operations, and transaction processing.
